# FitLog 项目日志

## 2026-10-28｜M0、M1 训练核心与轻像素页面

建立 `app`、纯 JVM `domain`、Android `data` 三模块，采用 Kotlin、Compose Material 3、Room 和手动依赖注入，最低支持 Android 8.0。

实现 19 个可搜索动作、自由训练、跨动作草稿保存、原子完成与撤销、会话恢复、上次完成记录预填和训练结束；重量以整数克保存，目标组数为 1～100，移除已完成组须确认，已结束会话禁止普通训练写入。

按 Soft Pixel 方案接入首页、动作库、训练记录与总结，统一青绿、浅紫、奶油黄配色，加入原创原生像素狐狸；页面直接观察数据库，只展示真实记录。模板、偏好、休息计时、历史热力图和备份留待后续阶段。

## 2026-10-28｜M2 模板、偏好与计时

补全模板创建、排序、目标编辑与复用，启动时复制为独立训练快照；接入可跳过的偏好引导、DataStore 设置、kg/lb、收藏与筛选。暂停时长和休息结束时间持久化，加入暂停恢复、跳过休息及结束反馈。训练写入按顺序执行，完成组读取最新持久化草稿，避免快速操作覆盖刚输入的数值。

## 2026-10-28｜M3 历史与备份

实现年度热力图、日期会话详情、动作真实重量与次数趋势及基础统计；只将已结束训练的完成组计入统计。增加版本化 JSON 导入导出和 Room 1→2 迁移，备份整批事务合并，相同记录去重、同 ID 不同记录拒绝，保留历史快照和草稿。

## 2026-10-28｜M4 动作内容与体验

动作库扩充至 42 个，补全中英文名称、文字说明、自定义与归档恢复；加入原创前后肌肉高亮示意、像素狐狸图标及可编辑的固定规则分化建议。补全暗色主题、大字体训练控件、触控区域、空状态和错误反馈，进度采用短暂平滑过渡；应用仅通过用户主动选择的本地 JSON 文件迁移数据。

## 2026-10-28｜输入修复与自主添加

搜索框独立保存编辑文字、光标和输入法组合状态，异步查询不再回写输入，并加入一键清空。移除自动分化建议与空进度展示，首次使用从空训练、空模板开始，由用户添加动作和训练安排；保留已有记录。

## 2026-10-28｜本机模拟器启动入口

可见模拟器启动脚本迁至 `/home/lzk/tools/launch-visible-emulator.py`，可直接执行；继续使用 FitLog 的 AVD 与日志目录，以及现有 Android SDK，启动不依赖当前工作目录。

## 2026-10-28～29｜训练流程、循环计划与隐私清除

主页加入自由训练与模板选择、待开始动作和醒目的开始／继续入口；仅点击开始后计时，返回主页暂停、进入后台继续，全部目标组完成或手动结束时停止，并通过持续通知返回训练页。添加动作固定在动作栏前端；历史定位当前月，加入颜色刻度、未完成状态、时间旁的简短感想及每日首场来源／后续加练标识。

模板页加入默认 7 天、最长 14 天的循环计划，逐日选择模板或休息；Room 升至 3，备份升至 2 并兼容旧版导入。设置加入删除全部本机信息，使用系统清除应用数据以删除数据库、偏好及缓存，重新打开回到首次设置。

引导页与主要短标题按可用宽度适度调整字号、保持单行，主页缩短装饰文案，训练卡片缩小装饰以增加动作名称空间。

## 2026-10-29｜像素小狗动画接入

以用户提供的小狗素材替换狐狸及启动图标，首页、引导、训练、总结与模板／历史空状态按待机、举重、休息、流汗、睡眠和庆祝分配动作。使用原始透明 PNG 帧与统一显示视窗，保留原动画节奏；位图复用、像素采样，后台停止播放并遵循系统动画缩放。

## 2026-10-29｜模板草稿与动作搜索

模板编辑在取消、系统返回和切换页面时提示保留草稿或放弃修改；草稿独立持久化，允许名称或动作列表尚未填完时保留，正式保存模板时同事务清除对应草稿。添加模板动作加入中英文名称搜索、一键清空和无匹配提示；Room 升至 4，保留既有记录与计划。

## 2026-10-30｜导航与休息计时布局

底部导航收敛为主页、动作、设置；历史改由主页今日训练旁入口打开，模板与计划统一从动作页进入，两个独立页面提供返回入口。组间休息倒计时和跳过操作移至动作切换栏下方、动画卡片上方，查看训练组时保持可见。

## 2026-10-30｜好友、私聊与动态（分阶段开发）

拟采用 Supabase 托管账号、社交数据、图片及实时通道，保留 Room 离线训练与现有计时。底部增加好友入口：列表头像进入个人主页，其余区域进入私聊，顶部进入动态流；主页展示资料、本人可见的好友备注、获授权的训练历史、实时训练卡片及倒序动态。训练历史与实时训练共享默认关闭，用户主动开启后好友才可查看，拟设置独立开关。

私聊规划持久化消息、离线补拉、发送重试与去重、未读、文字与图片、删除、单条及合并转发、引用回复和原消息定位；实时通道只通知变化，不承担历史存储。删除仅在自己的所有设备生效，以账号级隐藏记录避免重新同步后出现；撤回作为独立功能，引用与转发需分别处理原消息失效及已生成副本。云端以账号、好友关系和会话成员控制行与附件权限，拉黑、删好友或关闭共享后停止后续访问；已有本地训练绑定账号需明确确认，避免切换账号串用数据。

在线状态与训练状态分离，低频心跳和过期时间处理断网、进程终止及多设备状态；训练摘要由本地持久化记录生成，动作、组数、重量变化时更新，休息倒计时按结束时间本地计算。动态拟每批 20 条、聊天每批 50 条，以时间及 ID 游标分页、去重并限制驻留页数；图片用缩略图与有上限的缓存。离开动态页或应用退入后台时取消该页请求与订阅、释放列表和图片引用，训练服务与聊天持久化独立保留，不依赖退出回调清理。

实施按账号与权限、好友与个人主页、私聊、训练共享、动态与资源管理推进，逐阶段完成跨账号访问控制、断网恢复及既有记录迁移。账号登录方式和托管项目配置待定；后台消息通知另接适用的系统推送服务。原本机清除功能须与清除云端数据、注销账号分开定义。

好友基础接入：加入邮箱验证码登录、资料与 FitLog ID、精确查找、好友申请与接受／拒绝、私有备注和删除好友；云端建立账号资料、好友关系、共享偏好及权限接口，历史与实时训练共享默认关闭。登录令牌由 Android Keystore 加密保存并支持刷新、离线退出，原训练数据库与备份保持独立；私聊、动态、头像上传与实时训练共享尚未接入，开发版暂不合并稳定分支。

验证码邮件需先配置自定义 SMTP 才能编辑模板；开发联调采用 QQ SMTP，注册与登录模板改用一次性数字验证码。云端初始迁移由控制台执行，后续转用 CLI 时需先对齐迁移历史。

训练切换动作后的回顶部操作改为请求下次测量时定位，避免布局期间强制重测引发异常。
