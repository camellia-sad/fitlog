# FitLog 项目日志

## 2026-10-28｜M0、M1 训练核心与轻像素页面

建立 `app`、纯 JVM `domain`、Android `data` 三模块，采用 Kotlin、Compose Material 3、Room 和手动依赖注入，最低支持 Android 8.0。

实现 19 个可搜索动作、自由训练、跨动作草稿保存、原子完成与撤销、会话恢复、上次完成记录预填和训练结束；重量以整数克保存，目标组数为 1～100，移除已完成组须确认，已结束会话禁止普通训练写入。

按 Soft Pixel 方案接入首页、动作库、训练记录与总结，统一青绿、浅紫、奶油黄配色，加入原创原生像素狐狸；页面直接观察数据库，只展示真实记录。模板、偏好、休息计时、历史热力图和备份留待后续阶段。

## 2026-10-28｜M2 模板、偏好与计时

补全模板创建、排序、目标编辑与复用，启动时复制为独立训练快照；接入可跳过的偏好引导、DataStore 设置、kg/lb、收藏与筛选。暂停时长和休息结束时间持久化，加入暂停恢复、跳过休息及结束反馈。训练写入按顺序执行，完成组读取最新持久化草稿，避免快速操作覆盖刚输入的数值。

## 2026-10-28｜M3 历史与备份

实现年度热力图、日期会话详情、动作真实重量与次数趋势及基础统计；只将已结束训练的完成组计入统计。增加版本化 JSON 导入导出和 Room 1→2 迁移，备份整批事务合并，相同记录去重、同 ID 不同记录拒绝，保留历史快照和草稿。

## 2026-10-28｜M4 动作内容与体验

动作库扩充至 42 个，补全中英文名称、文字说明、自定义与归档恢复；加入原创前后肌肉高亮示意、像素狐狸图标及可编辑的固定规则分化建议。补全暗色主题、大字体训练控件、触控区域、空状态和错误反馈，进度采用短暂平滑过渡；应用仅通过用户主动选择的本地 JSON 文件迁移数据。

## 2026-10-28｜输入修复与自主添加

搜索框独立保存编辑文字、光标和输入法组合状态，异步查询不再回写输入，并加入一键清空。移除自动分化建议与空进度展示，首次使用从空训练、空模板开始，由用户添加动作和训练安排；保留已有记录。

## 2026-10-28｜本机模拟器启动入口

可见模拟器启动脚本迁至 `/home/lzk/tools/launch-visible-emulator.py`，可直接执行；继续使用 FitLog 的 AVD 与日志目录，以及现有 Android SDK，启动不依赖当前工作目录。

## 2026-10-28～29｜训练流程、循环计划与隐私清除

主页加入自由训练与模板选择、待开始动作和醒目的开始／继续入口；仅点击开始后计时，返回主页暂停、进入后台继续，全部目标组完成或手动结束时停止，并通过持续通知返回训练页。添加动作固定在动作栏前端；历史定位当前月，加入颜色刻度、未完成状态、时间旁的简短感想及每日首场来源／后续加练标识。

模板页加入默认 7 天、最长 14 天的循环计划，逐日选择模板或休息；Room 升至 3，备份升至 2 并兼容旧版导入。设置加入删除全部本机信息，使用系统清除应用数据以删除数据库、偏好及缓存，重新打开回到首次设置。

引导页与主要短标题按可用宽度适度调整字号、保持单行，主页缩短装饰文案，训练卡片缩小装饰以增加动作名称空间。

## 2026-10-29｜像素小狗动画接入

以用户提供的小狗素材替换狐狸及启动图标，首页、引导、训练、总结与模板／历史空状态按待机、举重、休息、流汗、睡眠和庆祝分配动作。使用原始透明 PNG 帧与统一显示视窗，保留原动画节奏；位图复用、像素采样，后台停止播放并遵循系统动画缩放。

## 2026-10-29｜模板草稿与动作搜索

模板编辑在取消、系统返回和切换页面时提示保留草稿或放弃修改；草稿独立持久化，允许名称或动作列表尚未填完时保留，正式保存模板时同事务清除对应草稿。添加模板动作加入中英文名称搜索、一键清空和无匹配提示；Room 升至 4，保留既有记录与计划。

## 2026-10-30｜导航与休息计时布局

底部导航收敛为主页、动作、设置；历史改由主页今日训练旁入口打开，模板与计划统一从动作页进入，两个独立页面提供返回入口。组间休息倒计时和跳过操作移至动作切换栏下方、动画卡片上方，查看训练组时保持可见。

## 2026-10-30｜好友、私聊与动态

社交使用 Supabase 托管账号、数据和私有图片，保留 Room 离线训练与既有计时。底部新增好友入口，头像进入个人主页，其余区域进入私聊，顶部进入倒序动态；个人主页展示资料、私有备注、获授权的训练历史和实时训练卡片。

接入邮箱验证码登录、资料与 FitLog ID、精确查找、好友申请、私有备注、删除好友及黑名单；令牌通过 Android Keystore 加密保存。新增私聊文字与图片、未读、引用定位、单条／合并转发、本人账号级删除与发送者撤回，独立 Room 缓存保存待发送队列；动态支持图片、点赞、评论及游标分页，头像进入个人主页。动态每页 20 条、聊天每页 50 条，限制驻留记录和图片缓存；页面退入后台取消刷新并释放列表与图片引用。既有私聊保留个人历史视图，已生成转发副本独立；合并记录支持单独转发，普通消息可多选合并。

训练历史和实时共享设为独立开关，默认关闭；上传前明确确认本机记录归属。训练状态在动作和组数变化后合并更新，并通过带过期时间的低频心跳维持，私聊前台约 5 秒刷新、好友状态约 15 秒刷新，不依赖常驻 WebSocket；后台训练沿用已有前台服务，系统后台消息推送尚未接入。云端迁移补充私有图片桶、消息隐藏、共享权限与旧消息定位，引用预览随原消息可见性变化。

验证码邮件需先配置自定义 SMTP 才能编辑模板；开发联调采用 QQ SMTP，注册与登录模板改用一次性数字验证码。云端初始迁移由控制台执行，后续转用 CLI 时需先对齐迁移历史。

训练切换动作后的回顶部操作改为请求下次测量时定位，避免布局期间强制重测引发异常。

## 2026-10-30｜我的页面与设置入口

底部最右侧改为“我的”，集中邮箱登录、头像、FitLog ID、资料编辑、训练共享与黑名单；好友页保留好友申请、私聊和动态入口。器械、训练偏好、单位、外观、备份与本机清除统一保留在独立设置页，由“我的”进入并可返回；清除操作仅影响本机，云端账号与社交记录保留。

## 2026-10-30｜部分设备认证连接重置

一位用户的手机在 App 与浏览器访问 Supabase 项目域名时均出现连接重置，切换 Wi-Fi 与手机流量后仍然失败；其他用户手机可直接访问。故障仅在该用户设备上复现，设备配置或网络路径的具体原因尚未确认。

## 2026-10-30｜社交细节与动作素材接入

客户端与云端评论删除权限统一限制为仅评论本人，动态作者不能删除他人的评论。头像采用按账号隔离、有上限的前台小图缓存，切页复用并在后台释放；个人与好友详情提供 FitLog ID 复制，“我的”首页卡片隐藏 ID。

接入用户提供的动作 GIF，按动作 ID 关联列表与详情，保留原素材；移除动作详情的肌群示意，未提供素材的动作不显示替代图。聊天输入法留白改由整个聊天布局统一处理，列表随键盘缩小，输入栏贴近键盘。

## 2026-10-30～31｜图片查看与训练动态分享

聊天与动态图片改为完整适配，点击可进入大图查看，支持缩放、平移、还原及多图切换；保留聊天图片长按操作。训练总结与历史感想旁新增分享到动态入口，先保存本地感想，再预填仅包含完成组的可编辑摘要，由用户确认发表，不改变历史或实时共享开关。

## 2026-10-31｜本地聊天、完整备份与应用更新

聊天历史、待发送队列和图片改为本机持久保存、按账号隔离，登出不清除；旧云端记录按双方落盘确认迁移，新消息仅临时中转，附件由定时清理函数处理。补充离线通讯录及本机消息优先读取，删除、撤回状态在恢复旧备份时保留。

本地主 JSON 升为 v3，兼容旧版并补入偏好、待开始动作、模板草稿、独立聊天数据区和本人动态副本；图片仅保存引用。云端私有备份包分文件保存记录与聊天／本人动态图片，保留最近三份；恢复前检查账号与记录冲突，不重新发表动态或开启训练共享。

主页新增手动及前台自动版本检查、更新提醒、下载进度和系统安装入口，安装前核对文件、包名、版本与签名；Supabase 独立公开桶托管更新文件，发布脚本生成对应 APK 的版本清单。自动清理由 Supabase Cron 每 15 分钟执行；首版更新文件尚待上传。

## 2026-10-31｜动作扩充、秒数记录与好友自动刷新

动作库扩充至 50 个，补入用户指定的八个动作，并按稳定 ID 接入全部 50 个动作 GIF，包含新版蝴蝶机夹胸及补齐的招财猫、哑铃前平举和绳索 Y 举。平板支撑按秒数记录，动作和训练快照保存独立单位，训练、模板、历史、分享及备份同步区分时长与次数；Room 升至 5，JSON 升至 4，保留旧库和旧备份兼容。

好友页进入时立即刷新并在前台定时更新，刷新保持现有列表、不占用操作进度，移除手动刷新入口与顶部刷新条。
